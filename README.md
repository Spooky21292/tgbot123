# Telegram-бот для ежедневной финансовой аналитики

Production-like бот на Python 3.11+, который:
- раз в день автоматически собирает рыночные данные и свежие новости,
- формирует осторожную аналитическую сводку (без категоричных рекомендаций),
- отправляет digest подписчикам в Telegram.

## Возможности

- Команды:
  - `/start` — подписка на ежедневную рассылку
  - `/stop` — отписка
  - `/digest` — вручную получить свежую сводку
  - `/ideas` — показать текущие идеи для наблюдения
- Планировщик ежедневной отправки (APScheduler).
- Хранение подписчиков в SQLite.
- Логирование ошибок сети и runtime-ошибок.
- Fallback при нехватке новостей.
- Подготовлен для деплоя на Railway.

## Быстрый запуск локально

### 1) Подготовка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 2) Настройка переменных

```bash
cp .env.example .env
```

Заполните:
- `TELEGRAM_BOT_TOKEN` — токен бота из BotFather
- `TIMEZONE` — например `Europe/Moscow`
- `DIGEST_HOUR`, `DIGEST_MINUTE` — время ежедневной рассылки
- опционально `FINNHUB_API_KEY`, `NEWSAPI_API_KEY` для расширения новостного покрытия

### 3) Запуск

```bash
python bot.py
```

## Как формируется аналитика

1. Сбор новостей за последние 24 часа из RSS (+опционально Finnhub/NewsAPI).
2. Сбор рыночных данных через `yfinance` (нефть, газ, золото, доллар, индексы, доходности, крупные акции, доступные тикеры РФ).
3. Вычисление дневных изменений.
4. Формирование digest:
   - главные новости,
   - срез по рынкам,
   - 3–5 идей для наблюдения,
   - 3–5 риск-факторов,
   - осторожные сценарии.

> В тексте используются вероятностные формулировки: «может получить поддержку», «может оставаться под давлением», «есть вероятность», «если тенденция сохранится», «стоит наблюдать».

## Частые проблемы

- **Ошибка `401 Unauthorized` / `InvalidToken` при старте**:
  1. Проверьте `TELEGRAM_BOT_TOKEN` в `.env` (без пробелов и кавычек).
  2. Убедитесь, что токен получен от BotFather для нужного бота.
  3. Если токен попал в логи/скриншоты, перевыпустите его через BotFather (`/revoke`) и обновите `.env`.

## Деплой на Railway

1. Создайте новый проект в Railway.
2. Подключите GitHub-репозиторий с этим проектом.
3. В Variables добавьте переменные из `.env.example`.
4. Укажите Start Command:

```bash
python bot.py
```

5. Redeploy.

### Рекомендации для Railway

- Используйте `TIMEZONE=UTC` или нужную вам локальную зону.
- Храните `SQLITE_DB_PATH` в persistent volume, если хотите сохранять подписчиков между пересборками.

## Ограничения и заметки

- Источники могут временно отдавать неполные данные; бот это переживает и выводит аккуратные fallback-сообщения.
- `yfinance` может возвращать задержанные котировки или `n/a` для части тикеров, особенно для отдельных регионов.
- Бот выдает аналитическую сводку и не является индивидуальной инвестиционной рекомендацией.
